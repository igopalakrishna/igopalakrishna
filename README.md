## Featured Projects

**[SignalLake](https://github.com/igopalakrishna/signallake)**
Cut log-analytics scan cost by partitioning event storage instead of scanning full datasets per query.
`FastAPI` `DuckDB` `Parquet` `Pydantic` `Docker`
Reduced data scanned by 92.7% (86.7 MB → 6.3 MB), validated by a pytest suite in CI.

**[ExpertMatchAI](https://github.com/igopalakrishna/ExpertMatchAI)**
Combined semantic and keyword search so expert matches stay relevant even when query wording differs from profile text.
`Next.js` `FastAPI` `FAISS` `BM25` `PostgreSQL`
Indexed 12,168 profiles, tested with Vitest, pytest, and Playwright.

**[NYC Subway Foot-Traffic Forecasting](https://github.com/igopalakrishna/nyc-subway-foot-traffic-prediction-and-forecasting)**
Connected historical ridership training with a simulated live stream to forecast station-level traffic continuously.
`Kafka` `Spark Structured Streaming` `MongoDB` `scikit-learn`
Processed roughly 13M historical MTA turnstile records.

**[Colorectal Cancer Survival Prediction](https://github.com/igopalakrishna/colorectal-cancer-prediction)**
Turned a clinical dataset into a tracked, reproducible survival-risk model instead of a one-off notebook.
`scikit-learn` `MLflow` `Kubeflow Pipelines` `Flask`
92.9% accuracy and 0.89 ROC-AUC on real clinical data.

**[VeriWire](https://github.com/igopalakrishna/VeriWire)**
Verified callers through identity and liveness checks before approving a high-risk wire transfer, with every decision logged.
`FastAPI` `LangGraph` `Deepgram` `Twilio`
Three-factor identity verification, covered by a 5-file pytest suite.
