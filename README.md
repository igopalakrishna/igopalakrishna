## Featured Projects

### [SignalLake](https://github.com/igopalakrishna/signallake)
Built a local-first operational analytics platform with partitioned storage and a SQL query layer.  
`FastAPI` `DuckDB` `Parquet` `Pydantic` `Docker`  
**Result:** Reduced data scanned by 92.7% from 86.7 MB to 6.3 MB, validated by pytest in CI.

### [ExpertMatchAI](https://github.com/igopalakrishna/ExpertMatchAI)
Combined semantic and keyword retrieval so expert matches remained relevant when query wording differed from profile text.  
`Next.js` `FastAPI` `FAISS` `BM25` `PostgreSQL`  
**Result:** Indexed 12,168 profiles and validated the system with Vitest, pytest, and Playwright.

### [NYC Subway Foot-Traffic Forecasting](https://github.com/igopalakrishna/nyc-subway-foot-traffic-prediction-and-forecasting)
Connected historical ridership analysis with simulated streaming ingestion and station-level forecasting.  
`Kafka` `Spark Structured Streaming` `MongoDB` `scikit-learn`  
**Result:** Processed roughly 13 million historical MTA turnstile records.

### [Colorectal Cancer Survival Prediction](https://github.com/igopalakrishna/colorectal-cancer-prediction)
Turned a clinical dataset into a tracked and reproducible survival-risk modeling workflow.  
`scikit-learn` `MLflow` `Kubeflow Pipelines` `Flask`  
**Result:** Reached 92.9% accuracy and 0.89 ROC-AUC on the documented dataset.

### [VeriWire](https://github.com/igopalakrishna/VeriWire)
Built a voice AI proof of concept for identity verification and controlled wire-transfer decisions in a mock banking environment.  
`FastAPI` `LangGraph` `Deepgram` `Twilio`  
**Result:** Implemented three-factor verification with coverage across five pytest files.

- Start with the simplest correct system, then measure before adding complexity.
- Make failures visible and recoverable through tests, logging, validation, and explicit fallback paths.
- Treat retrieval and ML quality as measurable product behavior, not only model output.
- Build for the next engineer through reproducible workflows, clear interfaces, and documented trade-offs.
